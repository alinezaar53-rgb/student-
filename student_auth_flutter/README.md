# Student Authentication System

نظام مصادقة طلابي تجريبي بأربع شاشات باستخدام Flutter وDart فقط، مع MVC + Repository Pattern.

## التشغيل
1. أنشئ مشروعاً جديداً: `flutter create student_auth`
2. استبدل مجلد `lib` في المشروع بالمجلد الموجود هنا.
3. من مجلد المشروع نفّذ:
   - `flutter pub get`
   - `flutter run`

لا توجد أي حزم خارجية مستخدمة.

## تجربة النظام
1. أنشئ حساباً من شاشة إنشاء الحساب.
2. سجّل الدخول باستخدام البريد الجامعي أو الرقم الأكاديمي وكلمة المرور.
3. لاستعادة كلمة المرور استخدم البريد أو الرقم الأكاديمي المسجل.
4. رمز التحقق التجريبي هو `123456`.

## ملاحظات
- البيانات محفوظة في الذاكرة فقط؛ عند إغلاق التطبيق وإعادة تشغيله تُحذف الحسابات التجريبية.
- لا يوجد إرسال بريد إلكتروني حقيقي أو اتصال بخادم.
- `Remember Me` محفوظ كقيمة في طلب تسجيل الدخول فقط، ولا ينفذ تخزيناً دائماً.
- رمز OTP الثابت للتجربة التعليمية فقط، ولا يصلح للاستخدام في تطبيق حقيقي.
